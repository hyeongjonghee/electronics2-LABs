1. 실험 11 · 업/다운 카운터

①개요

4비트 업/다운 카운터. rst가 최우선, enable일 때 down 여부에 따라 15↔0을 순환하며 증가·감소한다.

포트핀/제어
I/Oclk, rst, enable, down → value[3:0]
보드 매핑LED[3:0] = value, N8 = enable, K4 = rst, SW8 = down

②RTL

module counter4 (
    input wire clk, rst, enable, down,
    output reg [3:0] value
);
    always @(posedge clk) begin
        if (rst) value <= 4'd0;
        else if (enable) begin
            if (down) value <= value - 4'd1;
            else value <= value + 4'd1;
        end
    end
endmodule

2. 실험 12 · 클록 분주

①개요

DIVISOR로 클록을 나누어 duty 50%의 divided 출력과, 소비 가능한 한 클록 폭의 tick을 만든다. 보드에서는 ÷2·÷10·÷50·÷1000 네 개를 동시에 인스턴스화했다.

포트핀/제어
I/Oclk, rst → divided, tick
보드 매핑LED[3:0] = ÷2·÷10·÷50·÷1000, LED4 = tick (자동 동작, 버튼 불필요)

②RTL

module clock_divider #(parameter integer DIVISOR = 10) (
    input wire clk, rst,
    output reg divided,
    output wire tick
);
    localparam integer WIDTH = $clog2(DIVISOR);
    reg [WIDTH-1:0] count;
    assign tick = !rst && (count == DIVISOR - 1);
    always @(posedge clk) begin
        if (rst) begin count <= 0; divided <= 1'b0; end
        else begin
            if (count == DIVISOR - 1) count <= 0; else count <= count + 1'b1;
            if (count == DIVISOR/2 - 1) divided <= 1'b1;
            else if (count == DIVISOR - 1) divided <= 1'b0;
        end
    end
endmodule

보드 매핑LED[7:4] = stored, LED[3:0] = value, SW8 = load, SW7 = transfer, SW[7:4] = data_in

②RTL

module register_pair (
    input wire clk, rst, load, transfer,
    input wire [3:0] data_in,
    output reg [3:0] stored, value
);
    always @(posedge clk) begin
        if (rst) begin stored <= 4'd0; value <= 4'd0; end
        else begin
            if (load) stored <= data_in;
            if (transfer) value <= stored;
        end
    end
endmodule

6. 실험 16 · Moore 상태 머신

①개요

출력이 상태 그 자체인 Moore 머신. enable·advance가 모두 1인 클록 에지에서만 00→01→10→00으로 전이한다.

포트핀/제어
I/Oclk, rst, enable, advance → value[1:0]
보드 매핑LED7,LED8 = value(상태), SW1 = advance, N8 = enable

②RTL

module moore_cycle (
    input wire clk, rst, enable, advance,
    output reg [1:0] value
);
    always @(posedge clk) begin
        if (rst) value <= 2'b00;
        else if (enable && advance) begin
            case (value)
                2'b00: value <= 2'b01;
                2'b01: value <= 2'b10;
                default: value <= 2'b00;
            endcase
        end
    end
endmodule

7. 실험 17 · Mealy 상태 머신

①개요

출력이 상태와 현재 입력에 함께 의존하는 Mealy 머신. state는 클록 에지에서만 바뀌지만 value는 조합 논리라 입력 변화에 즉시 반응한다.

포트핀/제어
I/Oclk, rst, enable, bit_in → state, value[1:0]
보드 매핑LED6 = state, LED7,LED8 = value, SW1 = bit_in, N8 = enable

②RTL

module mealy_toggle (
    input wire clk, rst, enable, bit_in,
    output reg state,
    output wire [1:0] value
);
    always @(posedge clk) begin
        if (rst) state <= 1'b0;
        else if (enable && bit_in) state <= ~state;
    end
    assign value = !bit_in ? 2'b00 : (state ? 2'b01 : 2'b10);
endmodule

8. 실험 18 · 7세그먼트 자리 스캔

①개요

8자리를 한 번에 한 자리씩 빠르게 켜서(1 ms 점등 + 1 ms 암전) 사람 눈에는 8자리가 동시에 켜진 것처럼 보이게 한다.

포트핀/제어
I/Oclk, rst, enable, digits[31:0] → select[7:0], segments[7:0], index[2:0]
보드 매핑8자리 7세그먼트에 SW[7:4]가 첫 자리, 나머지는 1~7 고정 (자동 스캔, 버튼 불필요)

②RTL

module segment_scan8 (
    input wire clk, rst, enable,
    input wire [31:0] digits,
    output reg [7:0] select,
    output reg [7:0] segments,
    output reg [2:0] index
);
    reg blank;
    reg [3:0] nibble;
    always @(posedge clk) begin
        if (rst) begin index <= 0; blank <= 1'b1; end
        else if (enable) begin
            blank <= ~blank;
            if (!blank) index <= index + 1'b1;
        end
    end
    always @* begin
        nibble = digits >> (index * 4);
        select = blank ? 8'h00 : (8'h01 << index);
        case (nibble)  // LAB1 seg_decoder와 동일한 0~F 7세그 진리표
            4'h0: segments = 8'b11111100;  4'h1: segments = 8'b01100000;
