1. 실험 1 · LED 밝기 조절 (PWM)

① 목적

버튼을 누를 때마다 LED 8개의 밝기가 0 → 10% → … → 100% → 0으로 한 단계씩 바뀌게 한다. LED는 켜짐·꺼짐 두 상태만 있지만, 1초에 1,000번씩 "켜진 시간의 비율"을 바꾸면 눈에는 밝기가 바뀐 것처럼 보인다. 선풍기 날개가 빨리 돌면 하나의 원판처럼 보이는 것과 같은 원리다.

② 이론 · 설계 계산

한 PWM 주기의 클록 수 \(N\)과, 밝기 단계 \(L\,(0\le L\le 10)\)에서 High를 유지하는 클록 수 \(T_{on}\)은 다음과 같다.

$$N=\frac{f_{clk}}{f_{PWM}}=\frac{50\,000\,000}{1\,000}=50\,000,\qquad T_{on}=\frac{N\cdot L}{10}=5\,000\,L$$ $$D=\frac{T_{on}}{N}=\frac{L}{10}\quad(L=3 \Rightarrow D=30\%)$$

버튼은 기계 접점이라 누르는 순간 수 ms 동안 0과 1을 오간다(채터링). button_onepulse는 2단 플립플롭으로 비동기 입력을 클록에 맞춘 뒤, 값이 \(1\,000\,000\) 클록 = 20 ms 동안 그대로일 때만 한 클록짜리 펄스를 낸다.

`timescale 1ns/1ps
module lab3_led_pwm #(
    parameter integer CLK_HZ = 50_000_000,
    parameter integer PWM_HZ = 1_000,
    parameter integer LEVELS = 10,
    parameter integer DEBOUNCE_CYCLES = 1_000_000
) (
    input  wire clk_50mhz,
    input  wire rst_p,
    input  wire button,
    output wire [7:0] led
);

    wire press;
    wire pwm;
    reg [3:0] level;

    button_onepulse #(.STABLE_CYCLES(DEBOUNCE_CYCLES)) u_button (
        .clk(clk_50mhz), .rst_p(rst_p), .button(button), .pulse(press)
    );

    always @(posedge clk_50mhz or posedge rst_p) begin
        if (rst_p)
            level <= 4'd0;
        else if (press)
            level <= (level == LEVELS) ? 4'd0 : level + 1'b1;
    end

    pwm_channel #(.PERIOD_CYCLES(CLK_HZ / PWM_HZ), .LEVELS(LEVELS)) u_pwm (
        .clk(clk_50mhz), .rst_p(rst_p), .level(level), .pwm(pwm)
    );

    assign led = {8{pwm}};
endmodule
`timescale 1ns/1ps
module pwm_channel #(
    parameter integer PERIOD_CYCLES = 50_000,
    parameter integer LEVELS = 10
) (
    input  wire clk,
    input  wire rst_p,
    input  wire [3:0] level,
    output reg  pwm
);
    localparam integer COUNT_WIDTH = (PERIOD_CYCLES < 2) ? 1 : $clog2(PERIOD_CYCLES);
    reg [COUNT_WIDTH-1:0] count;
    integer threshold;

    always @* begin
        if (level >= LEVELS)
            threshold = PERIOD_CYCLES;
        else
            threshold = (PERIOD_CYCLES * level) / LEVELS;
    end

    always @(posedge clk or posedge rst_p) begin
        if (rst_p) begin
            count <= {COUNT_WIDTH{1'b0}};
            pwm <= 1'b0;
        end else begin
            pwm <= (count < threshold);
            if (count == PERIOD_CYCLES - 1)
                count <= {COUNT_WIDTH{1'b0}};
            else
                count <= count + 1'b1;
        end
    end
endmodule
`timescale 1ns/1ps
module button_onepulse #(
    parameter integer STABLE_CYCLES = 1_000_000
) (
    input  wire clk,
    input  wire rst_p,
    input  wire button,
    output reg  pulse
);

    (* ASYNC_REG = "TRUE" *) reg button_meta;
    (* ASYNC_REG = "TRUE" *) reg button_sync;
    localparam integer COUNT_WIDTH = (STABLE_CYCLES < 2) ? 1 : $clog2(STABLE_CYCLES);
    reg [COUNT_WIDTH-1:0] stable_count;
    reg accepted;

    always @(posedge clk or posedge rst_p) begin
        if (rst_p) begin
            button_meta <= 1'b0;
            button_sync <= 1'b0;
        end else begin
            button_meta <= button;
            button_sync <= button_meta;
        end
    end

    always @(posedge clk or posedge rst_p) begin
        if (rst_p) begin
            stable_count <= {COUNT_WIDTH{1'b0}};
            accepted <= 1'b0;
            pulse <= 1'b0;
        end else begin
            pulse <= 1'b0;
            if (button_sync == accepted) begin
                stable_count <= {COUNT_WIDTH{1'b0}};
            end else if (stable_count == STABLE_CYCLES - 1) begin
                stable_count <= {COUNT_WIDTH{1'b0}};
                accepted <= button_sync;
                pulse <= button_sync;
            end else begin
                stable_count <= stable_count + 1'b1;
            end
        end
    end
endmodule

⑤ 시뮬레이션

50,000클록짜리 주기를 그대로 돌리면 파형이 너무 길어진다. 테스트벤치는 파라미터만 줄여(CLK_HZ=1000, PWM_HZ=100) 한 주기를 10클록으로 만들고, 한 주기 안의 High 개수가 단계 값과 같은지 센다. 영화를 빨리 감기로 보되, 줄거리는 그대로인 것과 같다.

2. 실험 2 · RGB LED 색 조합 (3채널 PWM)

① 목적

빨강·초록·파랑 세 채널에 각자 PWM을 달아 버튼 3개로 섞는 비율을 바꾼다. 물감 세 통을 조금씩 섞어 원하는 색을 만드는 것과 같다. 실험 1의 pwm_channel과 button_onepulse를 그대로 세 번씩 재사용했다.

② 이론 · 설계 계산

$$D_R=\frac{L_R}{10},\quad D_G=\frac{L_G}{10},\quad D_B=\frac{L_B}{10}\qquad(\text{각 }L\in\{0,\dots,10\})$$

조합 가능한 색은 \(11^3=1\,331\)가지다. PWM 주파수는 실험 1과 같은 1 kHz(\(N=50\,000\))라서 깜빡임은 보이지 않는다. 보드의 RGB LED 4개는 같은 색으로 함께 켜진다(led_r = {4{pwm_r}}).

3. 실험 3 · 피에조 부저 (주파수 분주로 음 만들기)

① 목적

50 MHz 클록을 나눠 294 Hz 사각파를 만들고 피에조 부저로 "레(D4)" 음을 낸다. 줄넘기를 일정한 박자로 넘으면 줄이 같은 소리를 반복하듯, 1초에 294번 떨리는 신호가 그 높이의 소리가 된다.

② 이론 · 설계 계산

출력을 반주기마다 뒤집으므로 반주기 클록 수는 다음과 같다(정수 나눗셈).

$$H=\left\lfloor\frac{f_{clk}}{2f_{tone}}\right\rfloor=\left\lfloor\frac{50\,000\,000}{588}\right\rfloor=85\,034$$ $$f_{out}=\frac{f_{clk}}{2H}=\frac{50\,000\,000}{170\,068}\approx 294.0000\ \text{Hz}$$

평균율의 D4는 \(440\times2^{-7/12}\approx293.66\) Hz이므로 차이는 약 0.12%(2 cent)로 귀로는 구별되지 않는다.

`timescale 1ns/1ps
module lab3_piezo #(
    parameter integer CLK_HZ = 50_000_000,
    parameter integer TONE_HZ = 294
) (
    input  wire clk_50mhz,
    input  wire rst_p,
    output reg  piezo
);
    localparam integer HALF_PERIOD = CLK_HZ / (2 * TONE_HZ);
    localparam integer COUNT_WIDTH = (HALF_PERIOD < 2) ? 1 : $clog2(HALF_PERIOD);
    reg [COUNT_WIDTH-1:0] count;

    always @(posedge clk_50mhz or posedge rst_p) begin
        if (rst_p) begin
            count <= 0;
            piezo <= 0;
        end else if (count == HALF_PERIOD - 1) begin
            count <= 0;
            piezo <= ~piezo;
        end else begin
            count <= count + 1'b1;
        end
    end
endmodule

4. 실험 4 · 스텝 모터 (2상 여자 순서 만들기)

① 목적

스텝 모터의 네 입력(A, B, /A, /B)에 정해진 순서로 전류를 넣어 한 칸씩 돌린다. 계단을 한 칸씩 오르듯 순서를 앞으로 돌리면 정방향, 뒤로 돌리면 역방향이 된다.

② 이론 · 설계 계산

항상 두 상을 함께 켜는 2상 여자(full step) 순서를 쓴다. 매뉴얼 p.555에서 stepmotor[3:0]은 STEP_A, STEP_B, STEP_/A, STEP_/B다. 한 스텝마다 한 상만 바뀌고, A와 /A(B와 /B)가 동시에 켜지는 일은 없다.

statestepmotor[3:0]켜진 상 (bit3~0 = A, B, /A, /B)
00011/A · /B
10110B · /A
21100A · B
31001A · /B
$$T_{step}=\frac{f_{clk}}{f_{step}}=\frac{50\,000\,000}{100}=500\,000\ \text{클록}=10\ \text{ms}$$

1초에 100스텝이다. 스텝각이 1.8°인 모터라면 \(1.8^\circ\times100=180^\circ/\text{s}=30\) rpm이다(보드 모터의 스텝각은 확인하지 못했다).

    input wire direction,

5. 실험 5 · MM:SS 디지털 시계 (7세그먼트 4자리)

① 목적

1초마다 올라가는 분·초 시계를 만들고 7세그먼트 4자리에 MM.SS로 표시한다(분 1의 자리의 점을 구분자로 사용). 네 자리를 번갈아 아주 빨리 켜서, 손전등 네 개를 돌려 비추는데도 모두 켜져 보이는 것처럼 표시한다.

② 이론 · 설계 계산

$$1\ \text{s}=f_{clk}\ \text{클록}=50\,000\,000\ \text{클록}$$ $$T_{digit}=\frac{f_{clk}}{f_{scan}}=\frac{50\,000\,000}{4\,000}=12\,500\ \text{클록}=250\ \mu\text{s},\qquad T_{frame}=4T_{digit}=1\ \text{ms}$$

한 자리가 1 ms마다 다시 켜지므로(자리당 1 kHz) 깜빡임은 보이지 않는다. 카운터는 초 1의 자리 9 → 0일 때 초 10의 자리로, 59초 → 00초일 때 분으로 올림하며 59:59 다음은 00:00이다(주기 3,600 s).

세그먼트 비트 순서는 LAB2-08(보드 검증 완료)과 같은 seg_data[7:0] = {a,b,c,d,e,f,g,dp}, High = 켜짐이다. 자리 선택 seg_com은 Low = 선택이며 COM[3]~COM[0]을 쓴다. 매뉴얼 p.555에서 COM[7] = AR_SEG_S0(맨 왼쪽) … COM[0] = AR_SEG_S7(맨 오른쪽), seg_data[7] = AR_SEG_A … seg_data[0] = AR_SEG_DP임을 확인했다.

module mmss_counter #(
    parameter integer CLK_HZ = 50_000_000
) (
    input wire clk,
    input wire rst_p,

7. 실험 7 · UART 에코 (9600 bps, 8N1)

① 목적

PC 터미널에서 보낸 글자를 받아 그대로 돌려보내고(에코), 받은 글자의 ASCII 값을 LED 8개에 2진수로 보여준다. UART는 약속한 빠르기(보레이트)로 한 비트씩 차례로 보내는 방식이라, 보내는 쪽과 받는 쪽이 같은 박자로 손뼉을 치는 것과 같다.

② 이론 · 설계 계산

한 비트에 해당하는 클록 수를 반올림으로 구한다.

$$\text{DIV}=\left\lfloor\frac{f_{clk}+\text{BAUD}/2}{\text{BAUD}}\right\rfloor=\left\lfloor\frac{50\,004\,800}{9\,600}\right\rfloor=5\,208$$ $$\text{실제 보레이트}=\frac{50\,000\,000}{5\,208}\approx9\,600.61\ \text{bps},\qquad\text{오차}\approx+0.0064\%$$

UART는 한 글자(10비트) 동안 오차가 쌓여도 반 비트(5%) 안이면 되므로 충분히 작다. 한 글자 프레임은 시작(0) + 데이터 8비트(LSB 먼저) + 정지(1) = 10비트 = 약 1.04 ms다. 수신기는 시작 비트의 하강 에지를 본 뒤 DIV/2만큼 기다려 비트 한가운데에서 표본을 잡는다.

③ 포트 · 보드 매핑

핀 확인 완료 — USB_RXD = C6, USB_TXD = F6로 매뉴얼 p.586 USB to Serial(FT232R, J10 USB Type-B)과 일치한다. 회로도에서 FT232R의 TXD가 USB_RXD로 들어가므로 FPGA 입력은 C6이다. 같은 쪽의 RS-232 경로(UART_RXD = A5, UART_TXD = A3, ADM3202 · DB9)는 쓰지 않았다.

④ RTL

`timescale 1ns/1ps
module lab3_uart_echo #(
    parameter integer CLK_HZ = 50_000_000,
    parameter integer BAUD = 9_600
) (
    input wire clk_50mhz,
    input wire rst_p,
    input wire uart_rxd,
    output wire uart_txd,
    output wire [7:0] led
);
    localparam integer DIV = (CLK_HZ + BAUD/2) / BAUD;
    wire [7:0] rx_data;
    wire rx_valid;
    wire rx_framing_error;
    wire tx_ready;
    reg tx_valid;
    reg [7:0] tx_data;
    reg [7:0] last_data;

    uart_rx #(.DIV(DIV)) u_rx(
        .clk(clk_50mhz), .rst_p(rst_p), .rx(uart_rxd), .data(rx_data),
        .valid(rx_valid), .framing_error(rx_framing_error));
    uart_tx #(.DIV(DIV)) u_tx(
        .clk(clk_50mhz), .rst_p(rst_p), .valid(tx_valid), .data(tx_data),
        .ready(tx_ready), .tx(uart_txd));

    always @(posedge clk_50mhz or posedge rst_p) begin
        if (rst_p) begin
            tx_valid <= 0; tx_data <= 0; last_data <= 0;
        end else begin
            tx_valid <= 0;
            if (rx_valid) begin
                last_data <= rx_data;
                if (tx_ready) begin
                    tx_data <= rx_data;
                    tx_valid <= 1;
                end
            end
        end
    end
    assign led = last_data;
endmodule
`timescale 1ns/1ps
module uart_rx #(parameter integer DIV = 5208)(
    input wire clk, rst_p, rx,
    output reg [7:0] data,
    output reg valid,
    output reg framing_error
);
    (* ASYNC_REG="TRUE" *) reg [1:0] sync;
    reg [1:0] state;
    integer timer;
    reg [2:0] bitno;
    reg [7:0] shift;
    always @(posedge clk) begin
        if (rst_p) begin
            sync<=3; state<=0; timer<=0; bitno<=0; shift<=0;
            data<=0; valid<=0; framing_error<=0;
        end else begin
            sync<={sync[0],rx}; valid<=0; framing_error<=0;
            case(state)
                0: if(!sync[1]) begin timer<=DIV/2-1; state<=1; end
                1: if(timer!=0) timer<=timer-1;
                    else if(sync[1]) state<=0;
                    else begin timer<=DIV-1; bitno<=0; state<=2; end
                2: if(timer!=0) timer<=timer-1;
                    else begin
                        shift[bitno]<=sync[1]; timer<=DIV-1;
                        if(bitno==7) state<=3; else bitno<=bitno+1'b1;
                    end
                3: if(timer!=0) timer<=timer-1;
                    else begin
                        if(sync[1]) begin data<=shift; valid<=1; end
                        else framing_error<=1;
                        state<=0;
                    end
            endcase
      end
    end
endmodule

module uart_tx #(parameter integer DIV = 5208)(
    input wire clk, rst_p, valid,
    input wire [7:0] data,
    output wire ready,
    output wire tx
);
    reg [9:0] shift;
    reg [3:0] remaining;
    integer timer;
    assign ready = (remaining == 0);
    assign tx = ready ? 1'b1 : shift[0];
    always @(posedge clk) begin
        if(rst_p) begin shift<=10'h3ff; remaining<=0; timer<=0; end
        else if(ready) begin
            if(valid) begin shift<={1'b1,data,1'b0}; remaining<=10; timer<=DIV-1; end
        end else if(timer!=0) timer<=timer-1;
        else begin timer<=DIV-1; shift<={1'b1,shift[9:1]}; remaining<=remaining-1'b1; end
    end
endmodule

8. 고찰

  • 빌드 성공 ≠ 보드 동작. 새 장치 핀 30개는 빌드가 모두 성공한 뒤에도 근거가 없었다. 매뉴얼 각 실험 절의 핀표(p.555 · 568 · 578 · 586)와 한 줄씩 대조하고 나서야 보드에 올렸고, 그 결과 7개 회로가 한 번에 동작했다.
  • 매뉴얼 오타 1건. p.555 핀표의 CLED_R4 = K4는 같은 표의 rst(K4)와 겹친다. FPGA 핀 하나를 두 신호에 동시에 줄 수 없으므로 오타로 판단했고, 우리 값 R3로 4번째 RGB LED가 켜지는 것을 보드로 확인했다.
  • 스텝 모터 입력의 의미. 설계 때는 4비트를 A · B · C · D 네 코일로 가정했지만, 매뉴얼에서는 A · B · /A · /B(두 코일의 양 끝)였다. 순서를 다시 따져 보니 한 스텝마다 한 상만 바뀌고 A와 /A가 동시에 켜지지 않아 올바른 2상 여자 순서였다. 회전 방향만 교과서 순서와 반대다.
  • 푸시 키와 연속 동작. 키패드는 누르는 동안만 High라서, 계속 켜 두어야 하는 입력(스텝 모터 enable)에는 DIP 스위치가 더 알맞았다. RTL은 그대로 두고 XDC만 바꿔 두 버전을 모두 검증했다.
  • UART는 케이블부터. 처음에는 PC가 FT232R을 전혀 인식하지 못해 COM 포트가 없었다. FPGA 설계가 아니라 PC와 보드 사이 USB 연결 쪽 문제였고, 연결을 다시 확인해 USB Serial COM 포트가 잡히자 설계를 바꾸지 않고도 바로 에코가 동작했다. 보드에는 RS-232(A5/A3)와 USB(C6/F6) 두 경로가 있어 어느 쪽을 쓰는지 핀표로 먼저 확인해야 한다.
